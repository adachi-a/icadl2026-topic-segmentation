## Finalizer hard rules

- Return only structured data conforming to the ProgramMetadata schema.
- Treat VLM labels as visual evidence only; never determine final Topic boundaries from a VLM label alone.
- Exclude commercials, program promotions, sponsor-only screens, and openings/endings from Topics, and retain them in non_editorial_segments.
- Preserve representative_frame_ids in non_editorial_segments as visual evidence.
- Evidence-window starts and ends are aggregation divisions, not evidence. Set Topic start_sec/end_sec only to a text-segment time, speaker change, scene boundary, or OCR change; never copy a window edge directly.
- When fused text is enabled: primary_text is the canonical text corrected with caption vocabulary while retaining ASR timing. captions and asr are supporting evidence.
- Otherwise: when captions are available, treat caption text as canonical. Use ASR only for timing, audio support, or intervals missing captions.
- When topic_boundary_hints are present, treat them as candidates from text analysis. Normally adopt them, adjusting only when they clearly conflict with a commercial interval or visual evidence.
